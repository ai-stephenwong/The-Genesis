3. Transition Mechanics

Every transition between stages follows this deterministic sequence:

1

Guard Check

Are all dependencies complete with 0 validation failures? If any guard fails, the stage cannot start.

2

Stage Execution

Claude Code invoked via claude --print -p "run agent {name}". Each stage gets its own context window.

3

Validation Script

run-stage-checks.sh {stage} {project} — deterministic checks that catch issues agents cannot reliably self-check.

4

State Update

pipeline-run.json updated with status, timing, validation results. pipeline-log.md appended with event entry.

5

Decision

If validation passed → proceed to next stage. If failed → route to responsible agent for remediation. If gate → apply mode rules (auto-approve / ask human).

4. Remediation Flow

When a reviewing agent finds fixable issues, the fix routes through upstream validation before returning to the original reviewer.

Remediation Limits

LimitValueScope
Per-issue3 attemptsSame issue may be attempted at most 3 times
Per-stage total9 attemptsTotal fix attempts across all issues within one stage

Blocker Judgement (Two-Agent Rule)

When a limit is hit, two sub-agents are invoked in parallel:

  1. The reviewing agent that found the issue
  2. The solution-architect

Each returns BLOCKER or NON-BLOCKER. If either says BLOCKER → it IS a blocker (conservative rule).

VerdictAutopilotManual
BlockerSTOP pipeline. Log everything.STOP. Present to user.
Non-blockerLog as deferred. Continue.Ask user: "Continue? [Y/n]"

6. The Closed Loop

Pipeline Run
pipeline-run.json records per-stage metrics (time, remediations, validation pass/fail)
Bug Report
Produced by tester or discovered post-deploy
Retrospective
Phase 1: Implication Report → Phase 2: Agent scores, framework gaps, SDLC proposals, convergence analysis
Tribute → The Genesis
Proposals absorbed into agent_docs/generic/ → propagated to all child projects
Re-Run
Next pipeline benefits from updated standards
convergence-report.sh measures: is the loop working?

Convergence Measurement

MetricWhat it measuresGood trend
Process timeAre runs getting faster?Decreasing
Remediation roundsAre fewer fix cycles needed?Decreasing
Validation failuresAre fewer checks failing?Decreasing (key metric)
Retrospective scoreAre agent scores improving?Increasing

Verdict: CONVERGING failures trending down  |  FLAT no trend  |  DIVERGING failures trending up
